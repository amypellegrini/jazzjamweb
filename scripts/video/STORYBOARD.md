# Block chords video — storyboard (draft for review)

One row per sentence. **Score** = a short MuseScore snippet rendered from the same voicing data as
the article (spec: workbench `docs/specs/block-chords-harmonisation.md`). **Keys** = a
`piano-chord-charts` keyboard, recoloured to the article's colour code: melody crimson, chord tones
green, passing tones blue, left hand violet. **Cue** = the visual changes on that word, using the
narration's word timings. Subtitles show the sentence at the bottom; every sentence is followed by a
pause (proposed 1.2 s) so the visual can sit. White background, no boxes around the music.

`[example]` rows are the article's full examples, played with the sounding chord lit.
